# KitePrism

KitePrism enables scalable, distributed database management through cloud-based auto-scaling and load-balancing capabilities.

With KitePrism, you get a lightweight tool that stays out of your way.

**What you get**

- KitePrism enables scalable, distributed database
- management through cloud-based auto-scaling and
- load-balancing capabilities

## Key Features

- KitePrism enables scalable, distributed database
- management through cloud-based auto-scaling and
- load-balancing capabilities

## Technology Stack

- rust
- rust framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/KitePrism.git`
2. `cd KitePrism`
3. Install in editable mode: `pip install -e .`

## Configuration

KitePrism is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
